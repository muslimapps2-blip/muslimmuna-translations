# Muslim Muna – Quran translations

Translation files downloaded by the Muslim Muna app (one zip per language, <name>/001.txt … 114.txt, one ayah per line).

Sources: Tanzil.net (https://tanzil.net/trans/) and QuranEnc.com (King Fahd Complex). Texts are used unchanged.
German: Frank Bubenheim & Nadeem Elyas (QuranEnc german_bubenheim).
